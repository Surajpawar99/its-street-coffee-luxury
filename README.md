## 🚀 Key Features

1. **Pinned 400vh Hero Stage:**
   - 60fps high-DPI HTML5 canvas scrub transitioning through three artisanal coffee craft stages (Harvest Roast, 9-Bar Crema Extraction, Microfoam Latte Art).
   - Dynamic narrative caption bands and SVG circular progress indicator.
2. **Pune Shaniwar Wada Heritage:**
   - Authentic illustrated cup design honoring Pune's historic 18th-century palace fortress.
3. **Web Audio Ambient Coffee Lounge:**
   - Real-time procedural audio synthesis recreating cafe room acoustic warmth and smooth vinyl harmonics in E-flat major 7th.
4. **Authentic Menu Archive (Real Prices in INR):**
   - Classics: Espresso ₹79, Americano ₹89, Cappuccino ₹99, Cafe Latte ₹109
   - Dessert Coffees: Turkish Cappuccino ₹119, Hazelnut Latte ₹119
   - Frappes: Mocha Frappe ₹139, Signature Street Blast ₹139
   - Smoothies: Alphonso Mango ₹139, Blueberry Cookie ₹159
   - Refreshers: Mint Mojito ₹119, Cool Blue ₹119
   - One-tap WhatsApp ordering for every drink.
5. **Interactive Taste Profile Quiz:**
   - 3-step recommendation quiz computing ideal beverage pairings with direct order actions.
6. **Reservation & Franchise Drawer Modals:**
   - Seamless WhatsApp message formatters routing guest bookings directly to the cafe's floor manager.
7. **Strict 10k-Websites Compliance:**
   - 100% Vanilla HTML5, CSS3, JavaScript. Zero npm build steps. Zero forbidden buzzwords.
